The gate

Positions the Statute Agent will not defend never reach the calculator. That separation is what makes every euro auditable instead of merely plausible.

One tool, one holder

Only agent 03 is given lookup_statute, and it is instructed never to cite a provision it has not looked up. The other four cannot invent law because they cannot reach it.

Confidence travels with the money

Each position carries a score. Anything below 0.90 is surfaced to the user for confirmation rather than silently claimed.

Frozen for the stage

Output is written to data/case-lena.json and replayed by the demo — real pipeline, zero latency, no wifi dependency.
